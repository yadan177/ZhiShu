# 智枢岗位插件：UI 设计师（`zhishu-ui-design`）

- 适用角色：UI 设计师、交互设计师、体验设计师、设计系统维护者（覆盖 2D 与 XR 空间界面）。
- 关联底层规则：`common`、`ui-design`、`project-docs/ui-design`、`xr-common`（执行时动态读取目标项目 `.agent-rules/`，不复制规则正文）。
- 包含技能（6 个）：
  1. `ui-requirement-states` — 界面需求与状态梳理
  2. `ui-wireframe-layout` — 交互线框与布局方案
  3. `ui-design-system-setup` — 视觉风格与设计系统搭建
  4. `ui-xr-spatial-audit` — XR 空间界面规范检查
  5. `ui-handoff-checklist` — 设计稿走查与研发交付
  6. `ui-implementation-qa` — 界面实现还原度验收
