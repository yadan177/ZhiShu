# 交互线框与布局方案

## 1. 开始前核对

1. 优先读取项目 `.agent-rules/overrides.md`、`.agent-rules/ui-design/其他规则/02-交互设计规则.md`（若已安装）；若涉及 XR 空间界面，同步读取 `.agent-rules/ui-design/其他规则/07-XR空间界面规范.md`。
2. 核对目标视口尺寸范围（最小窗口宽度、标准分辨率或 XR 面板视距/张角）、现有导航框架（侧边栏 / 顶栏 / 抽屉）和既有页面模式。
3. 确认页面交互密度定位（如高频工具工作台 vs 内容阅读页 vs 沉浸空间面板）。

## 2. 执行步骤

1. **确定主骨架与视觉动线**：规划顶层区域划分（固定导航区 / 页头操作区 / 主工作区 / 辅助抽屉或弹窗），明确宽度/列数/固定与滚动区域边界，避免双重嵌套滚动条。
2. **合理分配承载容器**：
   - 列表与主内容在主工作区承载；
   - 详情查看、多选配置或表单编辑优先用**右侧滑出抽屉**保持上下文不丢失；
   - 高风险确认、差异预览、短表单使用居中**模态弹窗（Modal）**，禁止弹窗套弹窗。
3. **绘制清晰线框与页面流转图**：输出结构化区域栅格说明（ASCII/Markdown 布局图或 Figma 线框结构规格）+ Mermaid 页面流转图，标明每个交互入口的去向与返回路径。
4. **响应式与窄窗降级**：明确最小支持尺寸下的列数折行规则（如 4 列 → 2 列 → 1 列）、操作栏收折与截断优先级。

## 3. 输出结构

- **一、布局骨架与区域职责**（含固定/滚动边界与尺寸比例）
- **二、低保真区域布局图**（清晰表达模块相对位置与栅格结构）
- **三、页面流转与弹层/抽屉交互路径**（Mermaid `flowchart`）
- **四、关键交互细节与响应式降级说明**

## 4. 交付自检与红线

- 高频主流程点击层级合理，不把核心按钮藏进深层折叠菜单。
- 同类操作在相邻页面位置固定（如主按钮统一靠右、返回/取消统一靠左），不制造肌肉记忆冲突。
- 遵循去冗长原则，不为了“填满留白”硬塞说明卡片或营销 Banner。
- 在 Figma 等画布工具中落地多页线框或高保真稿时，同模块主页面与子态/弹窗必须归入同一 `Section` 按阅读流接续排布，并配合 `ui-handoff-checklist` 的 `figma-audit.js` 与整页总览图验收。
