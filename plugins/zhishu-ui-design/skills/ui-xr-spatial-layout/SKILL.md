# XR 空间界面布局设计

## 1. 开始前核对

1. 优先读取项目 `.agent-rules/overrides.md`、`.agent-rules/ui-design/其他规则/07-XR空间界面规范.md`、`.agent-rules/ui-design/其他规则/08-XR空间布局与摆放架构规范.md` 与 `.agent-rules/xr-common/其他规则/02-空间舒适度与防眩晕红线.md`（若已安装）。
2. 明确目标头显设备列表（Vision Pro / Meta Quest / PICO 等）、显示模式（VR 全沉浸 / MR 彩透 / 光学 AR）、主辅输入方式与核心任务涉及的 3D 主体/现实空间环境。
3. 核对项目既有设计系统、字体渲染方案（SDF / 系统原生字体）与移动一体机材质预算约束，避免设计无法落地的重模糊效果。

## 2. 空间布局设计步骤

1. **确定空间拓扑与多窗分区**：
   - 将主任务画布控制在水平 `≤ 35°–40°` 舒适区内（Meta 推荐核心安全视野约 `58° H × 54° V`）；超宽内容拆分为**主窗 + 左右内倾 `15°–25°` 折角侧翼**或**柱面弧形布局**，总常态工作区不超过 `±60°`；
   - 将导航栏、高频工具栏、媒体控制与底部移动抓手条剥离为独立**附属悬浮条（Ornament）**，确保**附属条宽度不超过其关联主窗口**并与主内容容器保持清晰物理间距；
   - 合理落位视距层级（近距直触 `< 0.46m`、中距主操作 `1.0–2.0m`、空间锚点关联 UI 建议 `≤ 3.0m`），**避开 `0.50–0.80m` 中距交互歧义带**。
2. **建立物理尺度与设计稿像素映射**：
   - 分别标明每个面板的**设计稿像素（px）、引擎物理宽高（m）、默认观看距离（m）、PPU/Canvas Scale（或 Meta `dp/m`）换算比例**与**距离缩放模式**（动态等角缩放 vs 真实物理尺寸）；
   - 按目标设备官方热区门槛核对控件尺寸与间距：**Apple visionOS 常规按钮中心距 `≥ 60pt` / 净间距 `≥ 16pt`**；**Meta Horizon OS 最小热区 `48dp×48dp` / 主控 `≥ 60dp×60dp` / 间距 `≥ 16dp` / 眼动目标 `≥ 3°` 视角**（配合不可见热区扩展 Hit Slop）。
3. **规划空间景深层级（L0–L4 Z-Layering）**：
   - 明确 3D 主体/环境（L0）、主窗基准面（L1 `0cm`）、悬浮附属条与 Hover 浮起（L2 `+2–4cm`）、下拉与 Tooltip（L3 `+4–6cm`）、模态弹窗与虚拟键盘（L4 `+6–10cm`）的物理 Z 偏移，以及弹窗打开时主窗后退/降暗规则。
4. **设计 3D 附属 UI、MR 透视背板与跨设备变体**：
   - 为 3D 物体标注/局部控件规划外轮廓避让位置与引导线，禁止遮挡 3D 主体正面；
   - 为 MR 模式设计经亮窗、暗场、杂乱桌面三类背景检验的高可读底板与描边，遵守移动一体机低 Overdraw 材质边界；
   - 输出面向目标设备的差异参数（如 visionOS 眼动 Hover 间距与原生 Glass vs Quest/PICO 手柄射线光标、裸手按压深度反馈与高不透明度微渐变底板）。

## 3. 输出结构

1. **一、空间设计基线与设备适配口径**（目标设备、显示模式、输入方式、尺度换算 PPU 与缩放模式）
2. **二、空间拓扑与布局分区图**（俯视空间角度分布示意 + 正面主窗/侧翼/附属条/3D 主体相对关系）
3. **三、面板摆放与景深规格表**：
   `面板名称 | 拓扑角色 | 物理宽高 (m) & 画布 (px) | 默认视距 (m) | 锚定与折角 | Z 层级偏移 | 悬停/热区与 MR 底板规格`
4. **四、面向 Unity / 跨端研发的交付清单**（含 Yaw-only 弹出基准、多窗并发上限、防穿模避让预期与真机必验项）

## 4. 交付自检与红线

- 严禁直接把 2D 桌面 12px/14px 字号或紧凑 16px 图标原样搬进中远距空间面板。
- 严禁在移动一体机（Quest / PICO）设计稿中依赖多层全屏实时高斯模糊却不提供低开销可落地替代方案。
- 所有面板必须明确物理 Z 偏移、非头锁锚定策略与热区安全间距，并区分“平面设计稿示意”与“头显真机已验证”。
