# AI 生成模型修复与重拓扑

## 1. 开始前核对

1. 优先读取项目 `.agent-rules/overrides.md`、`.agent-rules/3d-art/其他规则/01-图生3D与AI粗模精修规范.md`、`02-模型拓扑面数与LOD预算规范.md` 与 `03-UV展开与PBR贴图规范.md`（若已安装）。
2. 确认目标项目硬件档位（如移动 XR 一体机 vs PCVR）、该资产的 LOD0 面数预算、贴图分辨率上限及引擎着色管线（URP Metallic/Smoothness 等）。
3. 核对 AI 粗模现状（原始三角面数、是否存在非流形几何、破洞、孤立碎面、烘焙阴影或破碎 UV）。

## 2. 标准精修流水线（分步 SOP）

1. **几何清洗与尺寸归零**：
   - 校准真实米制尺度（1 单位 = 1 米），检查轴心（Pivot）归底居中或功能旋转点，清除缩放与旋转变换；
   - 删除内部不可见碎面、孤立顶点、重叠面与非流形边，修补破洞并统一法线朝向（杜绝局部翻面）。
2. **重拓扑与减面（Retopology）**：
   - 保留高模作为烘焙源；生成贴合轮廓的低模（硬表面保锐边与倒角结构，可动部位留足形变循环边），压入目标面数预算内。
3. **重展规范 UV**：
   - **严禁直接沿用 AI 自动切碎的碎片 UV**；按平滑组/硬边合理切缝，统一纹素密度（Texel Density），留足防渗透安全边距（Padding），保证 UV 利用率且无非故意重叠（镜像对称区按需偏移 1 象限烘焙）。
4. **高烘低与贴图去光影清洗**：
   - 从高模烘焙 Normal、AO、Curvature 与 BaseColor；
   - 使用 Delighting / 匀光处理清除 AI 贴图中烤死的黑影与假高光，重新校验 Metallic 与 Roughness/Smoothness 物理合理性（避免全图塑料感），并按引擎要求打包通道（如 MaskMap / ORM）。
5. **生成 LOD 链与简化碰撞体**：按预算制作 LOD1/LOD2，并为物理交互配置简单基础碰撞盒（Box/Capsule/Convex）而非直接拿高模当 MeshCollider。

## 3. 输出结构

- **一、粗模缺陷诊断摘要**（拓扑 / 几何 / UV / 贴图光照污染）
- **二、分步精修执行清单**（对应 Blender / Maya / Substance 操作要点）
- **三、目标指标对照表**（精修前 vs 精修后目标：面数、材质球数、UV 岛数、贴图尺寸与通道格式）
- **四、入库放行红线检查项**

## 4. 交付自检与红线

- **严禁将未经重拓扑和 UV 重展的 AI 原始粗模直接提交进 Unity/XR 正式资产目录**。
- 必须明确区分项目既定预算与通用参考预算，不得擅自拍死绝对面数上限替代项目实测预算。
