# 图生 3D 提示词与参考图准备

## 1. 开始前核对

1. 若项目已安装智枢规则，优先读取 `.agent-rules/overrides.md`、`.agent-rules/3d-art/15-AI通用入口规则.md` 与 `.agent-rules/3d-art/其他规则/01-图生3D与AI粗模精修规范.md`。
2. 明确资产类别（静态硬表面道具 / 有机摆件 / 可动部件 / 角色装备）、美术风格（写实 PBR / 轻写实 / 风格化）及真实物理尺寸（米制）。
3. 核对目标资产是否适合走图生 3D：带精密镂空、薄片玻璃、强机械装配或必须分件动画的资产，应提前规划**分件生成**或直接手工建模，不盲目整块生成。

## 2. 执行步骤

1. **制定参考图预处理标准**：
   - **纯白或中性灰纯底**，主体居中占比约 75%–85%，完整入画无裁边；
   - **均匀无方向漫反射光照（Flat/Studio Even Lighting）**，严禁强高光、强投影、地面反光或场景杂物（防止 AI 把黑影直接画死在 Albedo 贴图里）；
   - 复杂或非对称资产准备**正交前/侧/背/顶四视图**（或一致姿态多视图），确保比例严格统一；角色/拟人件采用标准 A-Pose 或 T-Pose。
2. **编写结构化图生图 / 图生 3D 提示词**：
   - 按 `主体品类 + 精确几何结构 + 材质分区描述 + 风格约束 + 均匀棚拍光 + 纯色背景 + 负面词（去投影/去景深/去文字水印/去透明重叠）` 输出中英双语模板。
3. **预设分件与后续精修策略**：提前标明哪些结构（如透明罩、屏幕、可旋转门把手）应剥离为独立子网格，减少后期拆模返工。

## 3. 输出结构

- **一、资产适用性评估**（适合整件 AI 生成 / 建议分件生成 / 建议手工制作）
- **二、参考图拍摄与预处理检查清单**（视角、构图、光照、去阴影、去遮挡）
- **三、可直接使用的生图 / 图生 3D 提示词**（正向提示词 + 负面提示词 + 参数建议）
- **四、下游精修预期提醒**（预计需重点修复的拓扑/法线/材质区域）

## 4. 交付自检与红线

- 严禁允许带强烈高光反射、环境光遮蔽死黑阴影或背景道具的图片直接喂给图生 3D 工具。
- 若涉及商业交付项目，必须提醒核对所用 AI 生成工具的商用授权条款并记录来源。
