# 智枢岗位插件：产品经理（`zhishu-product-pm`）

- 适用角色：产品经理、策划、项目负责人（覆盖 2D 多端软件与 VR/MR/AR 空间计算产品）。
- 关联底层规则：`common`、`product-pm`、`xr-common`（执行时自动读取目标项目 `.agent-rules/` 中已生效版本，不复制规则正文）。
- 包含技能（7 个）：
  1. `pm-requirement-research` — 需求调研与竞品分析
  2. `pm-product-structure` — 产品结构图生成
  3. `pm-flowchart-swimlane` — 业务流程图与泳道图生成
  4. `pm-prd-authoring` — PRD 需求文档编写
  5. `pm-xr-blindspot-audit` — 需求自检与 XR 盲区排查
  6. `pm-release-acceptance` — 版本验收清单生成
  7. `pm-meeting-to-tasks` — 会议纪要转待办
