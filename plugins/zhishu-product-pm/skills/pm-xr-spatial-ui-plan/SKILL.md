# XR 空间界面规划

## 1. 开始前核对

1. 若项目已安装智枢规则，优先读取 `.agent-rules/overrides.md`、`.agent-rules/product-pm/其他规则/03-XR产品体验与验收准出规则.md`、`.agent-rules/xr-common/其他规则/02-空间舒适度与防眩晕红线.md`；若同时安装了 `ui-design`，同步读取 `.agent-rules/ui-design/其他规则/08-XR空间布局与摆放架构规范.md`。
2. 明确产品运行前提（缺失项不得脑补，先列假设再集中确认）：
   - **目标设备与最低档位**：Apple Vision Pro / Meta Quest / PICO 一体机 / PCVR 串流，及是否多设备共用；
   - **显示与场景模式**：VR 全沉浸、MR 彩色透视还是光学 AR；
   - **用户姿态与活动空间**：坐姿桌面、站姿原地还是自由大空间行走；
   - **主辅输入方式**：眼动+捏合、6DoF 手柄射线、裸手直触/远距捏合，以及单手/输入断连降级预期。

## 2. 空间 UI 规划步骤

1. **划分信息归属：独立空间窗口 vs 3D 物体附属 UI**：
   - 将全局菜单、设置、资产库、协作聊天、文档/报表归为**独立空间窗口**；
   - 将 3D 模型热点标注、部件局部参数、底座控制环归为 **3D 物体附属 UI**，明确不得遮挡 3D 主体核心观察面。
2. **分配视距分区与布局拓扑**：
   - 区分**近距直触层**（`< 0.46m` 屈臂内，按目标设备校准）、**中距主操作层**（`1.0–2.0m`，大看板至 `2.5m`）、**远距环境层**（空间锚点及关联 UI 建议 `≤ 3.0m` 保证稳定追踪，更远仅做环境导视），**明确避开 `0.50–0.80m` 中距交互歧义带**（防用户不知该直触还是射线）；
   - 规划超宽工作台如何拆分为**主窗 + 内倾侧翼 / 弧形排布**，并将导航、工具条、抓手条剥离为外部**附属悬浮条（Ornament，宽度不超主窗）**，确保核心高频任务落在水平 `±30°` 主舒适区。
3. **定义窗口生命周期与多窗调度规则**：
   - 写明各窗口的**触发时机、锚定模式**（世界锚定 / 惰性跟随 / 手部控制器跟随，严禁默认头锁）、**同屏最大并发窗口数**、二级内容采用“主窗内切换 / 侧翼展开 / 阶梯多窗”中的哪一种；
   - 明确距离缩放偏好（动态等角缩放 vs 真实物理尺寸）、视角重置（Recenter）与窗口召回路径。
4. **界定 3D / MR 防穿模与多设备差异需求**：
   - 定义遇到真实墙面、桌面或大型 3D 物体时的预期行为（前推避让、贴墙吸附或紧凑降级），确保 MR 不遮挡脚下安全视线；
   - 对照 Vision Pro / Meta Quest / PICO 差异矩阵，在需求中写清目标设备的输入触发与系统保留手势避让边界。

## 3. 输出结构

1. **一、空间场景与设备基线**（目标设备、VR/MR 模式、用户姿态、主辅输入与未确认假设）
2. **二、空间 UI 清单与摆放规格表**：
   `模块/窗口 | 归属类型（独立窗/3D附属/附属条） | 视距层级 | 布局拓扑与锚定模式 | 多窗并发/切换规则 | 3D/MR 避让与召回要求`
3. **三、跨岗位交接要点**（分别列出交付给 UI 设计师的视觉/尺度细化项与交付给 Unity/跨端研发的交互/避让工程项）
4. **四、可测验收准出项**（坐/站姿弹出高度、多窗不重叠、穿模避让、视野重置与目标设备输入切换等可验证条件）

## 4. 交付自检与红线

- 严禁只输出传统 2D 页面树而不说明三维视距层级、独立窗/3D 附属归属和多窗调度关系。
- 严禁将单一平台交互范式（如 Vision Pro 眼动注视）默认假设为 PICO/Quest 手柄项目的通用前提。
- 涉及头部硬锁、过近贴脸弹出或遮挡 MR 安全通道的设想，必须主动拦阻并给出舒适替代方案。
