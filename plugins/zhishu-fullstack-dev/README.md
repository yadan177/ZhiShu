# 智枢岗位插件：全栈开发工程师（`zhishu-fullstack-dev`）

- 适用角色：前端开发、后端开发、桌面端开发、全栈工程师（覆盖 JavaScript / TypeScript / Go / Java / Python）。
- 关联底层规则：`common`、`javascript`、`typescript`、`go`、`java`、`python` 及配套 `project-docs/*`（执行时仅动态读取当前项目实际技术栈已安装的 `.agent-rules/`，不复制规则正文）。
- 包含技能（7 个）：
  1. `fs-code-review` — 代码审查与风险排查
  2. `fs-api-contract-sync` — 接口契约与前后端联调核对
  3. `fs-arch-sequence-diagram` — 系统架构与时序图生成
  4. `fs-ui-component-audit` — 组件与页面样式走查
  5. `fs-db-migration-check` — 数据库与迁移变更检查
  6. `fs-test-generation` — 自动化测试生成
  7. `fs-doc-changelog-sync` — 技术文档与变更日志同步
