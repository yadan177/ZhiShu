# 组件与页面样式走查

## 1. 开始前核对

1. 优先读取项目 `.agent-rules/overrides.md`、`.agent-rules/javascript/其他规则/13-React组件规则.md`（或 `16-Vue组件规则.md`）、`14-CSS与样式体系规则.md` 及 `.agent-rules/ui-design/`（若已安装）。
2. 核对项目既有前端技术栈与样式体系（如独立 CSS 变量 vs Tailwind vs CSS Modules、React 19 vs Vue 3），**遵循项目现有体系，禁止擅自引入未授权 UI 库或 CSS 框架**。
3. 核对项目特殊 UI 约定（例如是否禁用系统原生 `<select>` 必须使用自定义下拉组件、是否要求极简去冗长说明文案、白底图标容器规范等）。

## 2. 六维走查清单

1. **设计令牌与样式整洁度**：检查是否存在散落硬编码色值/间距/圆角、样式选择器泄漏、`!important` 滥用或未使用的死样式；优先绑定项目 CSS 变量/设计令牌。
2. **布局健壮性与极值容错**：检查超长标题、长路径（`min-width: 0` + `text-overflow: ellipsis` + `title`）、窄窗口自适应折行、双滚动条冲突及 `z-index` 层级遮挡。
3. **完整交互与数据状态**：检查默认/悬停/按下/聚焦/禁用态、空态、加载态、报错提示与高风险操作写入锁（防止连点重复提交）。
4. **语义 HTML 与基础无障碍（a11y）**：按钮使用 `<button type="button">` 而非裸 `<div>` 绑点击，弹窗/抽屉含 `role="dialog"` / `aria-modal` 与合理焦点/Esc 关闭支持，表单控件关联 `<label>`。
5. **前端渲染与副作用安全**：排查无效重渲染、未清理的事件监听/定时器/异步请求竞态（组件卸载后 `setState` 导致脏状态）、列表 `key` 误用数组下标。
6. **文案与术语统一**：核对界面文案是否来自统一术语表且与既有页面风格一致。

## 3. 输出结构

- **一、走查结论摘要**（通过 / 需修复后交付）
- **二、问题明细表**：`严重度 | 文件:行号 | 类别（样式/状态/a11y/性能/合规） | 问题描述 | 推荐改法`
- **三、实测与待界面目视复核项**（明确区分静态代码检查发现与需在真实浏览器/桌面端窗口核验的项）

## 4. 交付自检与红线

- 严禁仅读代码就宣称“界面视觉完美无错位”，未启动页面目视或截图验证时必须明确注明。
- 发现违反项目本地 UI 覆盖规则（如擅用原生下拉框、堆砌大段解释文案）时标为必改项。
