# 02 - 空间舒适度与防眩晕红线

> - 🟢 本文件适用于 XR 项目的相机运动、位移交互、空间视野布局、MR 透视环境与感官舒适度设计及审查。
> - 🔴 不适用：替代医学评估或无视具体目标人群（如青少年、首次体验者、工业现场人员）的额外安全法规。

---

## 1. 视觉-前庭冲突与防眩晕红线

眩晕（Cybersickness）的核心诱因是视觉运动信号与内耳前庭感知冲突。以下为跨岗位必须共同守住的红线：

- 🔴 **禁止未经用户主动触发而强行接管或锁定头部姿态**：严禁做强制运镜、镜头震屏（Screen Shake）、视角倾斜（Roll）或把 UI/场景硬锁在头部视线正中随头抖动。
- 🔴 **禁止低帧率或高频帧时抖动上线**：追踪到光子延迟（Motion-to-Photon Latency）异常或长时间掉帧重投影时，必须先解决性能问题，不得以“轻微卡顿可接受”放行。
- 🔴 **平滑移动与旋转必须提供舒适度保护**：
  - 优先提供**瞬移（Teleport）**与**分段转向（Snap Turn，如 30°/45°）**作为新手默认或可选模式；
  - 若业务确需连续平滑移动，采用恒定速度减少持续加减速，提供**动态视野收缩晕影（Comfort Vignette）**与固定参考系（如座舱/地面网格），并在设置中允许用户关闭或切换舒适档位。
- 🔴 **避免剧烈视差与双目深度冲突**：禁止大面积物体紧贴双眼前（过近于相机近裁剪面）强迫眼睛持续对焦冲突，禁止左右眼渲染内容、光照或后处理不一致导致视觉撕裂。

❌ 反例：为了营造“爆炸震撼感”，在 VR 头显中沿用 2D 游戏做法给主相机施加 0.8 秒剧烈镜头晃动，且弹出锁死在屏幕正中的全屏提示。

✅ 正例：通过环境物体微震、空间音频低频冲击、手柄触觉震动与可控外围视觉反馈表达冲击感，保持主相机严格跟随用户真实头部追踪；提示面板以世界空间或带阻尼的惰性跟随方式放置在舒适视距内。

## 2. 人体工学与空间视野分布

空间内容摆放必须尊重真实人体颈部转动范围与手臂自然姿态，避免“大猩猩臂（Gorilla Arm）”疲劳和长期仰头/低头劳损：

| 空间区域 | 人体工学要点 | 设计与布局约束 |
|---|---|---|
| **主视觉舒适区** | 自然平视及略微俯视（水平约 ±30° 内，垂直略低于视平线） | 核心操作面板、主任务目标与高频反馈必须落在主舒适区内 |
| **外围信息区** | 水平约 ±30°–±60°（轻微转头即可达） | 适合辅助导航、次要信息与环境线索，不放高频确认按钮 |
| **近距直触交互区** | 舒适屈臂伸手可达范围（通常约 0.45–0.65m，按坐/站姿校准） | 需双手直触操作的小型交互件放置在胸前偏下自然高度，避免持续举高过肩 |
| **中远距射线交互区** | 约 1.2–3.0m（主面板常见舒适视距区间） | 结合射线瞄准与清晰悬停反馈，目标尺寸随视距按角尺寸同步放大 |

- 🔴 所有长时交互流程必须评估**用户姿态**（坐姿 / 站姿 / 轮椅或受限桌面空间），不得强迫用户频繁转身 180°、大幅弯腰或跨出物理安全边界（Guardian / 安全围栏）。
- 🔴 首次进入或切换姿态时提供便捷的**视角重置（Recenter）**机制，且高度基准应兼容不同身高用户，不把固定绝对世界高度当作所有用户的眼高。
- 🔴 **跨岗位空间 UI 摆放底线**：首次弹出面板必须基于当前头部水平朝向（Yaw-only，忽略俯仰 Pitch 与翻滚 Roll）在舒适视距与略低于视平线处生成；超宽界面拆为主窗 + 内倾侧翼或弧形排布，多层级面板使用真实物理 Z 偏移，严禁穿模插入 3D 主体或真实墙面。详细布局拓扑与主流设备（Vision Pro / Meta Quest / PICO）适配矩阵见 `.agent-rules/ui-design/其他规则/08-XR空间布局与摆放架构规范.md`（若项目已安装 `ui-design`）。

## 3. MR 透视（Passthrough）与现实环境安全

当应用运行在彩色或黑白透视 MR 模式时，必须额外遵守物理世界安全底线：

- 🔴 **保留物理环境警觉**：不得用不透明虚拟大面片完全遮挡用户脚下或移动方向上的真实障碍物，引导移动时始终优先提示注意周围环境。
- 🔴 **真实光照明暗不可控**：MR 透视画面可能是亮白窗边、杂乱桌面或昏暗房间，虚拟 UI 与 3D 锚定物不能假设纯黑背景，必须验证高反差/复杂纹理背景下的边界辨识度。
- 🔴 **空间遮挡与物理一致性**：虚拟物体贴墙、贴桌放置时须核对平面识别误差与深度遮挡异常情况，识别失败时提供手动微调或无平面回退方案。
- 🔴 **隐私与空间数据边界**：涉及环境网格、房间布局、手部或眼动数据时，遵循最小权限原则并明确用户授权与系统权限弹窗流程。

## 4. 音频、光照与感官安全

- 🔴 避免高对比度大面积高频闪烁（防范光敏性不适），控制场景瞬时从极暗切到纯白的高亮度冲击。
- 🟡 善用空间化音频（Spatial Audio）引导用户注意视场外事件，替代强行旋转视角或刺眼全屏箭头。
- 🟡 交互反馈遵循“视觉 + 轻触觉/短音频”克制协同，避免无意义的持续高强度手柄震动或嘈杂提示音。
