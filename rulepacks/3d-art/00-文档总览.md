# 00 - 三维资产规范总览

> - 🟢 本规则库适用于实时 3D 与 XR（VR / MR / AR）项目的三维建模、图生 3D AI 粗模精修、重拓扑、UV 与 PBR 贴图及 FBX / glTF 资产导出入库。
> - 🔴 不适用：离线影视 CG 高模渲染流程，或以单一项目的面数/分辨率上限替代其他项目的硬件档位预算。

---

## 1. 目标与边界

实时 XR 三维资产不仅追求静态观感，更要求在双目高刷新率与移动芯片内存带宽限制下保持干净拓扑、低采样开销、零导入返工。随着图生 3D（如 Tripo / 混元 3D / Hyper3D 等）进入日常生产管线，本规则库明确“**AI 负责快速起型，人工与规范把关精修入库**”的工程底线。

- 🔴 **AI 生成粗模不得未经体检与修复直接导入正式引擎场景**；必须完成拓扑清理、重拓扑、UV 重展、贴图去高光烘烤（De-lighting）与规范导出。
- 🔴 单资产面数、LOD 档位、贴图尺寸与材质球数量必须服从目标项目硬件档位预算（XR 项目结合 `xr-common`），不以离线渲染效果牺牲实时帧率。
- 🔴 模型比例单位、世界朝向、枢轴点（Pivot）与冻结变换（Transform Applied）必须在导出前处理干净，禁止依赖引擎内手工调缩放补偿。
- 🔴 资产命名、目录归属与入库质检清单须同步交付，确保 TA 与 Unity 研发可直接接入自动化导入校验。
- 🟡 重复型小道具与环境模块优先复用模块化网格、通用 Trim Sheet 与共享材质球，减少 DrawCall 与显存膨胀。

## 2. 生产工作路径

| 生产方式 | 标准路径 | 关键质检关口 |
|---|---|---|
| **图生 3D 辅助生产** | 参考图准备 → 生成粗模 → 几何体检与清理 → 重拓扑与烘焙 → UV/PBR 去光修正 → 导出与入库清单 | 禁直出高密乱面、必须 De-lighting、检查非流形与反法线 |
| **传统 DCC 建模（Blender / Maya / Max）** | 灰盒比例确认 → 高/低模与 LOD → UV 展开与纹素校准 → PBR 贴图打包 → 规范导出 | 比例 1m 基准、LOD 链完整、无空节点与多材质浪费 |
| **存量资产优化与入库审查** | 扫描面数/贴图/材质/Pivot → 识别超标项与冲突 → 批处理修复脚本 → 复检入库 | 不破坏原有动画骨骼绑定与场景锚点 |

❌ 反例：把图生 3D 生成的 12 万三角面、带烘焙阴影高光、缩放为 `0.01`、轴心偏离 2 米、包含 6 张 4K 未压缩贴图的模型直接拖进移动 XR 工程。

✅ 正例：先用图生 3D 完成概念体块，在 Blender 中清理内部废面与非流形结构、重拓扑到目标档位面数并烘焙法线与 AO、剥离光照烘烤还原纯净 PBR 贴图、冻结变换归零 Pivot 后导出校验入库。

## 4. 规则等级与维护

| 标识 | 含义 |
|---|---|
| 🔴 | 适用条件满足时必须执行 |
| 🟡 | 推荐，结合资产重要级与项目硬件档位权衡 |
| 🟢 | 可选，仅在带来明确生产或性能收益时采用 |

- 🔴 具体面数上限、纹素密度目标、命名大小写前缀和导出目录结构以项目事实文档或 `.agent-rules/overrides.md` 为准；本包提供行业通用分级方法与必查红线。

## 5. 完成检查

- [ ] 几何拓扑无非流形、孤立顶点、重叠面与反转法线；AI 粗模已完成精修与重拓扑。
- [ ] 面数、LOD、材质球数与贴图分辨率符合当前项目硬件档位预算。
- [ ] UV 展开无严重拉伸与非法重叠，PBR 贴图已剥离错误烘焙光照并按项目约定打包通道。
- [ ] 比例单位、朝向、Pivot 与变换已冻结归零，FBX / glTF 导出无残留相机、灯光或历史节点。
- [ ] 已产出可核对的美术资产入库清单与已知问题说明。
