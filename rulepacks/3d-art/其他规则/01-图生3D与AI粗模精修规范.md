# 01 - 图生 3D 与 AI 粗模精修规范

> - 🟢 本文件适用于在三维生产管线中引入图生 3D / 文生 3D 工具（如 Tripo、混元 3D、Hyper3D 等）时的参考图准备、AI 粗模准入体检、重拓扑修复与贴图去光精修。
> - 🔴 不适用：直接将 AI 粗模用于最终发布，或把 AI 概念原型当作已完成入库标准的实时引擎资产。

---

## 1. 图生 3D 输入参考图与提示词规范

高质量输入能减少 60% 以上的后期拓扑与贴图返工。生成前必须先准备合规参考图：

- 🔴 **主体纯净无遮挡**：单主体居中、纯色或干净低干扰背景、无水印/文字/边框/前景裁切，避免复杂场景杂物被误识别成粘连几何体。
- 🔴 **中性均匀布光（Flat / Studio Lighting）**：参考图避免强方向硬阴影、刺眼高光反射与极端彩色环境光，否则 AI 会把阴影和高光直接“焊死”在基础色贴图（Albedo）里。
- 🔴 **正交清晰视角与结构完整**：优先采用略带立体感的三分之四视角或正/侧/背多视图输入；角色与可动资产优先 A-Pose / T-Pose，双臂与躯干留清晰间隙防止网格粘连。
- 🟡 **对称与分件思维**：需要独立运动、开合、发光或替换材质的部件（如门扇、仪表指针、玻璃罩、武器配件），应拆件生成或手工补建，不把整套可动机构生成为一块实心死网格。

## 2. AI 粗模准入体检（禁止直出进引擎）

所有图生 3D 产出的原始网格（通常为高密无序三角面或体素重建网格）在进入项目前，必须逐项完成以下体检：

| 体检项 | AI 粗模常见缺陷 | 处理红线 |
|---|---|---|
| **拓扑结构** | 密度极不均匀、密集碎三角面、局部扭曲撕裂 | 🔴 禁止直接进引擎；静态道具经可控重拓扑/减面，关键资产与变形区必须重构干净四边面布线 |
| **几何完整性** | 非流形边（Non-Manifold）、内部隐藏废面/空腔、零面积面、孤立顶点、局部破洞 | 🔴 导出前必须 100% 清理干净；避免法线烘焙黑斑与渲染穿帮 |
| **法线与光滑组** | 局部反转法线、硬表面棱角发软像橡皮泥 | 🔴 统一外部法线朝向，按硬表面折角重新标定锐边（Sharp Edge）或光滑组 |
| **UV 碎片化** | 自动生成上百块细碎 UV 岛、严重留白浪费与 Mipmap 渗色黑缝 | 🔴 严禁保留 AI 自动碎片 UV；重拓扑后按接缝规则重展 UV 并重新烘焙贴图 |
| **贴图烘烤光照** | Albedo 中混入强烈假阴影、假高光与脏噪点 | 🔴 必须执行去光处理（De-lighting），金属度/粗糙度按真实物理材质重制 |
| **比例与枢轴** | 随意尺寸、歪斜朝向、原点飘在半空 | 🔴 按现实 1m 比例校准、摆正前向、重设合理落地/装配 Pivot 并冻结变换 |

## 3. 重拓扑与细节烘焙策略

根据资产在 XR 场景中的观看距离与交互需求，分级决定 AI 粗模的精修深度，避免过度投入或质量失守：

- **英雄资产 / 近距可抓取交互道具 / 角色**：
  - 🔴 仅将 AI 粗模作为**高模雕刻底型（Base Sculpt）**使用；手工或半自动重拓扑出干净可控低模，独立拆分可动部件与透明玻璃件，再从高模烘焙 Normal / AO / Curvature 贴图并重绘规范 PBR 材质。
- **中距常规静态道具**：
  - 🟡 在清理非流形、内部废面与修平硬边后，可采用可控 Quad Remesh + 局部手工修剪关键轮廓线与 UV 接缝，再将原高模细节烘焙到新低模 UV 上。
- **远景纯装饰背景物**：
  - 🟡 在严格满足面数、单材质球与干净 UV 留边的前提下允许更轻量自动化减面，但仍须清理内部废面、反转法线与错误缩放。

❌ 反例：直接给 AI 生成的 8 万面雕塑套一次自动减面到 5 千面，不修 UV 也不去光，导入 Unity 后远看全黑缝、光照一打全是假高光。

✅ 正例：先清理内部废面并保留高模，重拓扑至 3,500 面并重展 3 块整洁 UV 岛，从高模烘焙切线空间法线与 AO，去光还原纯净 Albedo 后再配真实 Roughness。

## 4. 来源记录与合规底线

- 🔴 使用第三方图生 3D 平台生成的资产，必须在资产入库清单中标注**生成工具、账号归属/商业许可状态、参考图来源与人工精修责任人**，严禁使用无版权授权的他人成品图直接“图生 3D”进入商业发布包。
- 🟡 保留一份原始参考图与精修前后的关键量化对比（如 `85k → 3.2k tris`，`UV 碎片清理 + De-lighting`），便于团队复盘提效与审计追踪。
