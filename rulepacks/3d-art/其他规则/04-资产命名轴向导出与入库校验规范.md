# 04 - 资产命名轴向导出与入库校验规范

> - 🟢 本文件适用于三维资产的坐标系比例、枢轴点（Pivot）、命名目录、FBX / glTF 导出设置及入库质检清单。
> - 🔴 不适用：强行覆盖目标项目既有资产命名模板或既有引擎导入管线约定。

---

## 1. 比例单位、朝向与变换冻结

- 🔴 **真实世界 1:1 米制比例**：实时 XR 项目统一以 **1 单位 = 1 米（Meter）** 为基准建模（除非项目明确另有声明）。双目立体视觉对物体尺寸误差极其敏感，比例偏差 20% 就会在头显里显得像玩具或巨人国。
- 🔴 **统一正面朝向与上方向**：导出前按目标引擎坐标系确认正前方向与上方向（如 Blender `Z-Up` 导出至 Unity `Y-Up` 时统一使用经过验证的导出预设，确保导入引擎后无需在场景里给每个物体手工旋转 `-90°`）。
- 🔴 **冻结变换（Apply Transforms）**：所有导出网格的缩放必须归为 `(1, 1, 1)`，静态物件旋转归零，严禁携带负缩放（Negative Scale，会导致面片翻转与碰撞体异常）。
- 🔴 **合理枢轴点（Pivot）**：
  - 落地家具、仪器、建筑模块：Pivot 置于**底部几何中心（Z/Y=0 贴地）**；
  - 可旋转/开合部件（门扇、旋钮、指针）：Pivot 精准落在**真实旋转轴心**；
  - 手持可抓取道具：按项目约定置入自然握持重心或单独提供标准 Grip 挂点空节点。

## 2. 导出文件清理与格式核对（FBX / glTF）

导出正式包前，必须彻底清理 DCC 工程冗余数据：

- 🔴 **清理无关场景对象**：移除默认相机、测试灯光、参考图背景板、空占位组、未使用的材质槽、残留历史记录与隐藏草稿层。
- 🔴 **明确贴图交付方式**：
  - 项目采用独立贴图目录统一管理材质时，FBX **不内嵌贴图（Embed Media 关闭）**，防止多资产重复打包同一张贴图导致体积暴涨；
  - 采用 glTF / GLB 作为跨工具预览或独立轻资产交换格式时，按项目约定核对 PBR 扩展与外部引用路径。
- 🔴 **骨骼与动画分离（动态资产）**：带蒙皮的角色/机械，导出前核对最大单顶点骨骼影响数（移动 XR 通常严控 ≤ 4 根骨骼/顶点）、剔除非变形辅助控制骨骼，并将基础网格与动作片段按项目约定分离导出。

## 3. 目录树、命名与跨项目资产复用规范

### 3.1 推荐目录树与命名约定

若项目尚无既有 3D 资产目录与命名体系，建议采用“共享底材层 + 分域资产层 + 实验隔离层”结构，并全英文、仅字母数字下划线（禁中文与空格）：

```text
Assets/Art/Models/
├── _Common/                 # 跨模型 / 跨项目共享底材库（严禁反向引用具体业务场景）
│   ├── Materials/           # 通用基础材质（金属 / 塑料 / 玻璃 / 木纹等主材质实例）
│   ├── TrimSheets/          # 通用拼接贴图集与公用材质（建筑/道具高频复用）
│   └── Textures/            # 通用无缝平铺 PBR 贴图（Tileable Textures）
├── Props/                   # 常规道具（每个独立资产建子目录：SM_<域>_<名>/）
│   └── SM_<域>_<名称>/
│       ├── SM_<域>_<名称>.fbx
│       ├── Materials/       # 仅本资产专有材质球（优先复用 _Common）
│       ├── Textures/        # 仅本资产专有烘焙贴图（Normal / ORM / BaseColor）
│       └── Preview.png      # 可选：入库预览缩略图
├── Characters/              # 角色与骨骼资产（网格、骨骼、动画片段分离）
├── Environments/            # 场景模块化建筑件（Modular Kit）与地形物件
└── _Sandbox/                # 原始 AI 粗模与临时测试文件（严禁正式场景引用、不入库）
```

| 对象类型 | 建议命名模式 | 示例 |
|---|---|---|
| 静态网格 / 模型 | `SM_<领域>_<名称>_<变体>` | `SM_Lab_Microscope_01` |
| 骨骼蒙皮模型 | `SK_<领域>_<名称>` | `SK_Avatar_HandLeft` |
| LOD 子网格 | `<主模型名>_LOD0` / `_LOD1` / `_LOD2` | `SM_Lab_Microscope_01_LOD1` |
| 材质球 | `M_<主名称>` 或 `MI_<主名称>` | `M_Lab_Microscope` |
| PBR 贴图 | `T_<主名称>_<通道缩写>`（`_BaseColor` / `_Normal` / `_ORM` / `_Emissive`） | `T_Lab_Microscope_ORM` |

- 🔴 **项目既有约定优先**：同一项目内必须只执行一套命名与目录约定；若同时安装了 `unity`（默认材质前缀 `Mat_`）或 `ta-vfx-shader`，须在项目 `.agent-rules/overrides.md` 中确立唯一前缀与目录映射，严禁同一仓库混用 `M_`、`Mat_`、中英文、拼音和 `Cube.003` / `Material.001` 默认名。

### 3.2 跨项目可复用三维资产标准

- 🔴 **单向依赖与零场景硬耦合**：`Props/`、`Environments/` 等成品目录只允许单向引用 `_Common/` 与自身子目录，严禁依赖 `_Sandbox/`、具体场景灯光探针或业务脚本，确保可整文件夹打包为 `.unitypackage` / UPM Package 迁入新工程直接运行。
- 🔴 **优先模块化与 TrimSheet 复用**：墙体、管线、展台、高频金属/塑料件优先采用统一栅格尺度的模块化拼接件（Modular Kit）与 `_Common/TrimSheets/` 共享材质，减少独享大图贴图与材质球总数。
- 🟡 **沉淀资产复用卡片**：入库资产同步记录三角面数（LOD0–LOD2）、贴图分辨率与通道方案、材质数、米制包围盒尺寸、来源/许可与已验硬件档位，便于团队跨项目检索复用。

## 4. 美术资产入库质检清单

每次向引擎仓库或团队资产表（如飞书多维表格）提交三维资产前，必须完成并附带以下自检记录：

- [ ] **来源标识**：已注明制作方式（手工 / 图生 3D 精修）与商业合规许可状态。
- [ ] **拓扑指标**：已填报 `LOD0` 及各级 LOD 三角面数、无非流形/孤立点/反法线/内部废面。
- [ ] **变换比例**：符合 1 单位 = 1 米真实比例，缩放 `(1,1,1)`，无负缩放，Pivot 位置正确。
- [ ] **UV 与贴图**：无非法重叠与拉伸，Lightmap UV2 干净（静态物体），数据图线性空间与通道打包正确。
- [ ] **目录与复用**：归档于约定目录且单向依赖 `_Common/`，无残留相机/灯光/默认 `Material.001`，可独立导出复用且物理碰撞体按需分离。
