# 03 - UV 展开与 PBR 贴图规范

> - 🟢 本文件适用于实时 3D 与 XR 资产的 UV 展开、纹素密度、光照贴图 UV2、PBR 贴图制作、通道打包与压缩策略。
> - 🔴 不适用：将固定贴图分辨率或单一引擎通道布局强加给采用不同管线的项目。

---

## 1. UV 展开与纹素密度（Texel Density）

- 🔴 **纹素密度一致**：同一资产或同一场景中处于相同观看距离的表面，保持接近的纹素密度，避免桌面高清如照片而旁边按钮糊成马赛克。
- 🔴 **UV 接缝（Seams）隐藏与留边（Padding）**：
  - 接缝尽量隐藏在模型背面、底面、自然结构折角或硬边处；
  - UV 岛之间必须留出足够像素边距（随目标贴图尺寸等比调整，避免低级 Mipmap 采样时邻岛颜色渗漏出黑边/白边）。
- 🔴 **UV 空间利用率与方向**：
  - 有效 UV 覆盖率尽量高（常规非对称资产建议目标在 70%–85% 区间），避免半张贴图大片空白；
  - 带文字、木纹、拉丝金属或各向异性纹理的 UV 岛保持统一朝向与最小畸变；
  - 对称部件或高度重复面在**不需要独立烘焙光照/非对称做旧**时，可将重叠 UV 岛移出 `0–1` 主象限（偏移 `+1`）以防烘焙冲突。

## 2. 光照贴图第二套 UV（Lightmap UV2）

对于需要烘焙光照的静态场景资产：

- 🔴 **严禁任何重叠或越出 `[0, 1]` 范围**：哪怕 1 像素重叠都会导致烘焙阴影错误投射到其他面。
- 🔴 **留足独立岛间距**：Lightmap 分辨率通常远低于材质贴图，UV2 必须预留更宽松的岛间距以防烘焙光影渗色。
- 🟡 若依赖引擎自动生成 Lightmap UV，导入后必须实际检查光照烘焙预览结果，复杂结构优先在 DCC 中手工展开可控 UV2。

## 3. PBR 材质与贴图真实性红线

- 🔴 **Albedo（基础色）必须纯净无光照**：严禁在 Albedo 中保留明显方向阴影、强镜面高光或纯黑/纯白极限值（物理上极少存在 `0%` 或 `100%` 反射率，过黑会丢失暗部细节，过白会在光照下过曝发炸）。
- 🔴 **区分金属与非金属物理口径**：金属度（Metallic）原则上呈近二值分布（金属接近 `1`，绝缘体接近 `0`，仅在脏污/氧化过渡边有少量灰度）；粗糙度/光滑度贴图决定真实质感层次，避免全局平涂单一数值导致塑料感。
- 🔴 **色彩空间严格区分**：
  - 颜色类贴图（Albedo / Emissive）使用 **sRGB**；
  - 数据类贴图（Normal / Metallic / Roughness / Smoothness / AO / Mask）必须设为 **Linear（取消 sRGB）**，否则金属高光与法线方向会全部错误。

## 4. 通道打包、材质球收敛与压缩策略

在移动 XR 一体机上，贴图带宽与采样次数往往比纯面数更容易拖垮帧率：

- 🔴 **单资产尽量收敛材质球数量**：普通静态道具力争使用 **1 个材质球**（或将同类物体合图进同一套 Texture Atlas / Trim Sheet），严禁一个简单道具拆分 5–10 个独立材质槽导致 DrawCall 翻倍。
- 🔴 **灰度数据贴图必须通道打包**：禁止把 Metallic、Roughness/Smoothness、AO 分别存成三张独立 RGB 贴图浪费显存与采样器；按项目着色器约定合并到单张贴图的 R/G/B/A 通道（例如 Unity URP Standard Metallic Map 或通用 ORM `R=AO / G=Roughness / B=Metallic`）。
- 🔴 **贴图分辨率按面积与视距分级**：分辨率必须为 2 的幂次方（POT，如 256 / 512 / 1024 / 2048），按项目硬件预算分级指定，不给 10 厘米小零件盲目配 2K/4K 贴图。
- 🔴 **目标平台硬件压缩与 Mipmap**：
  - 移动 XR（Android / PICO 等）通常优先采用 **ASTC** 块压缩（法线与高清 UI/文字贴图用更精细块尺寸，常规漫反射用更省带宽块尺寸，具体按项目实测画质选型）；桌面 PCVR 常用 BC 格式；
  - 3D 空间世界物体贴图原则上**开启 Mipmap**，关闭 Mipmap 会在头显中引发剧烈远距闪烁噪点并增大纹理缓存未命中开销；
  - 仅在真正需要透明通道时保留 Alpha，无透明需求的贴图必须去除无用 Alpha 通道。

❌ 反例：给一把普通实验台小扳手配 4 张独立 4K 贴图（Albedo、Metallic、Roughness、AO 全带 Alpha 且全部勾 sRGB），导入移动一体机后单件道具占去数十 MB 显存。

✅ 正例：小扳手合并进实验台工具组共用 1 套材质球与通道打包贴图，数据图关闭 sRGB、去除冗余 Alpha、开启 Mipmap 与平台 ASTC 压缩。
