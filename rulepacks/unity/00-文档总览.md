# 00 - Unity AI 编码规则总览

> - 🟢 本规则库适用于 Unity 项目的 C#、Prefab、Scene、Shader、ScriptableObject、项目配置与客户端集成工作。
> - 🔴 不适用：Unity 引擎底层源码、美术资源制作流程、PICO XR/Spatial 技术选型和服务端内部实现。

---

## 1. 核心原则

1. 规则的目标是把架构边界、业务约束与编码经验转化为可执行的决策依据，使 AI 输出的代码可维护、可验证且符合项目既有约定。
2. 项目代码、配置、包、场景与部署事实优先于本规则库中的通用示例；没有证据时不得猜测。
3. 不过度设计：优先完成最小可验证改动，未经授权不升级依赖、迁移架构或批量重构。
4. 本库保留丰富的专题经验；[15 - Unity AI 通用入口规则](./15-AI通用入口规则.md) 只负责说明 AI 如何在真实项目中选择和执行这些规则。

## 2. 适用方式与优先级

| 优先级 | 依据 |
|---|---|
| 1 | 用户当前任务、法律与安全要求、工具限制 |
| 2 | 目标工程代码、依赖、配置、测试、构建与既有项目约定 |
| 3 | `.agent-rules/overrides.md` 中的项目覆盖规则 |
| 4 | [15 - Unity AI 通用入口规则](./15-AI通用入口规则.md) |
| 5 | 当前任务相关的 Unity 专题规则 |

等级标识含义如下：

| 标识 | 含义 |
|---|---|
| 🔴 | 已满足适用条件时必须遵守的约束；偏离需有明确授权或项目证据 |
| 🟡 | 有条件的推荐做法；需结合项目现状、平台与成本判断 |
| 🟢 | 可选方案；仅在项目已采用或用户明确选择时使用 |

## 4. 文档关系

```text
15 AI 通用入口
        |
        +--> 01 / 02 / 10：C# 与架构基础
        +--> 03 / 07 / 09：性能、定位与资源
        +--> 04 或 05：按项目已采用的 UI 体系选择；XR 空间 UI 结合 17
        +--> 06 / 08 / 11：项目工程与协作
        +--> 12 / 13 / 14：网络、服务集成与安全
        +--> 16：Bug 定位、根因确认与修复验证
        +--> 17：XR 空间 UI 摆放、生成、跟随、防穿模与一体机性能实现
```

- UI Toolkit 与 UGUI 不应因本规则库而混用；以目标项目已采用的 UI 体系为准。
- 资源、网络、服务端与安全专题存在联动，但不应在客户端规则中替代服务端的授权、校验、审计与数据所有权设计。
- PICO 平台 SDK 选型与特定平台集成，若项目已安装 `pico` 规则包请查阅 `.agent-rules/pico/PICO Unity SDK.md`，并以目标项目已安装的 SDK 和平台文档为准。
- XR 跨岗位硬件档位、防眩晕与真机验证基线，以及 URP 渲染合批、VFX Overdraw、Shader 立体渲染与变体、资产导入校验规范，若项目已安装对应可选包，分别查阅 `.agent-rules/xr-common/15-AI通用入口规则.md` 与 `.agent-rules/ta-vfx-shader/15-AI通用入口规则.md`。

## 5. AI 工具接入

安装由 智枢 CLI 和目标工具适配器负责。适配器只做入口导航，完整规则始终维护在本规则包中。

## 6. 文档维护

- 新建或改写规则文档时，如项目已安装 `rule-authoring` 规则包，遵守 `.agent-rules/rule-authoring/规则文档编写格式规范.md`；未安装时先确认适用规范。
- 修改专题规则后，同步检查本总览中的任务查表和交叉链接。
- 涉及特定 Unity 版本、包、框架、平台、命令或架构时，必须说明适用条件、验证方式与例外，不能把示例写成默认事实。
- 旧版专题内容及适配器入口的演变以 Git 历史为准。
