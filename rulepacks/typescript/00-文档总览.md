# 00 - TypeScript AI 编码规则文档总览

> - 🟢 本规则库适用于 TypeScript 项目（先读取 `../javascript/` 运行时基线，再按任务选择本目录的类型、编译配置与工具链专题）；React / Vue / Node.js / Electron / CLI 等生态均以仓库实际事实为准。
> - 🔴 不适用：替代 JavaScript 运行时基础规则（见 [JavaScript 文档总览](../javascript/00-文档总览.md)）、框架深度用法，或将示例中的 TypeScript 版本、模块解析策略、严格选项与运行时校验库当作所有项目的默认前提。

---

## 1. 核心原则

1. 项目的 `package.json`、锁文件、`tsconfig*.json`、运行时版本、构建配置和现有脚本优先于本规则库示例；本规则中的新版本能力和工具示例不构成升级要求。
2. 优先完成最小可验证改动；未经授权不升级 TypeScript、切换模块解析、批量开启严格选项、替换 ESLint 配置或引入新依赖。
3. 不确定时说明证据缺口或询问用户，不以通用经验或 AI 幻觉补全项目事实，不过度设计。

## 2. 规则等级与优先级

| 等级 | 标识 | 含义 |
|------|------|------|
| 必须 | 🔴 | 当前适用场景必须遵守；无法执行时说明原因、范围和风险 |
| 推荐 | 🟡 | 满足适用条件时优先评估；项目事实、风险和成本不支持时不采用 |
| 可选 | 🟢 | 按项目实际灵活选择 |
| 安全 | 🟠 | TS 项目运行时安全详见 [11 - 安全规则](../javascript/其他规则/11-安全规则.md)，按实际威胁与项目边界执行 |

优先级依次为：用户当前任务与安全限制、目标工程代码/依赖/配置/测试和已有项目约定、`.agent-rules/overrides.md` 中的项目覆盖规则、[09 - TypeScript AI 通用入口规则](./09-AI通用入口规则.md)（及上游 [15 - JavaScript AI 通用入口规则](../javascript/15-AI通用入口规则.md)）与当前任务相关专题规则。

## 6. AI 工具接入与维护

规则包版本、依赖与规则清单以同目录 `pack.json` 为准。安装由智枢 CLI 和目标工具适配器负责；适配器只做入口导航，完整规则维护在本规则包中。

- 🔴 修改专题规则后，同步检查本总览的任务查表、交叉链接、入口路由和 `pack.json` 清单。
- 🔴 不把特定 TypeScript 版本、模块解析策略、严格选项、运行时校验库或 lint 工具写成默认事实；需说明适用条件和验证方式。
- 🟡 新增规则前先确认现有 JS/TS 专题无法承载，避免与 `../javascript/` 重复或碎片化。
