# 00 - 技术美术规范总览（TA：特效 / Shader / 渲染）

> - 🟢 本规则库适用于实时 3D 与 XR（重点面向 Unity URP 移动 XR 一体机及 PCVR）的渲染管线配置、合批、VFX 特效、Shader 编写、变体治理、资产导入校验与真机性能剖析。
> - 🔴 不适用：离线光线追踪电影渲染，或用桌面 GPU 性能表现掩盖移动 XR 一体机的瓦片渲染（TBDR）带宽与 Overdraw 瓶颈。

---

## 1. 目标与边界

技术美术（TA）是连接三维美术表现力与实时引擎稳定帧率的核心防线。在移动 XR 一体机上，双目立体渲染与瓦片架构使**半透明 Overdraw、Shader 变体卡顿、破坏 SRP Batcher 合批与昂贵后处理**成为最常见的掉帧根因。

- 🔴 **双目立体渲染正确性优先**：所有自定义 Shader、屏幕空间特效与后处理必须显式验证单通道立体渲染（Single-Pass Instanced）下的左右眼一致性，严禁出现单眼消失、深度偏移或视野错位。
- 🔴 **帧率与填充率服从项目硬件档位预算**：特效表现力必须在 Overdraw、粒子数、DrawCall 与带宽预算内达成（XR 项目对齐 `xr-common`），不得以掉帧换炫酷。
- 🔴 **变体可控与零首帧卡顿**：严控 `multi_compile` 关键字膨胀，打包前必须核对变体裁剪与预热策略，防止真机运行时触发 Shader 编译尖峰掉帧。
- 🔴 **自动化资产导入校验不静默篡改美术源文件**：校验脚本以清晰报错、分类告警与显式确认修复为原则，防止破坏既有资产配置。
- 🟡 在满足目标画质的前提下，优先用材质合批、贴图通道打包与 Tight Mesh 裁切等结构性优化，再考虑降低特效清晰度或粒子数。

## 2. 工作路径

| 任务类型 | 建议路径 | 核心证据 |
|---|---|---|
| 渲染管线与材质治理 | 核对目标渲染管线与立体模式 → 检查 SRP Batcher 兼容性 → 审查实时光/阴影/后处理 | 合批统计、Frame Debugger 截帧分析、带宽影响说明 |
| VFX 特效体检与优化 | 统计发射器与同屏粒子峰值 → 审查半透明 Overdraw 与网格裁切 → 验证对象池与 Prewarm | Overdraw 视图截图、粒子峰值表、真机帧时对比 |
| Shader 编写与审查 | 明确目标管线与立体宏 → 核对精度与采样开销 → 治理变体关键字 → 跨 API 编译验证 | Shader 源码、变体计数、双目真机渲染验证记录 |
| 资产导入校验与真机剖析 | 编写只读审计或受控导入规则 → 在真机热稳态抓取 Profiler / RenderDoc → 输出瓶颈归因报告 | 真机热稳态剖析报告、瓶颈排序与可落地优化项 |

❌ 反例：为了实现酷炫的体积烟雾，在移动 XR 一体机中叠加 80 个覆盖全屏 60% 面积的矩形半透明粒子，且自定义 Shader 未做立体眼索引适配，导致真机单眼错乱且帧率暴跌至 28fps。

✅ 正例：使用 Tight Mesh 紧密裁切粒子透明边、合并 Flipbook 序列帧、将同屏贴脸半透明层数控制在预算内，在 Shader 中完整接入立体渲染宏并通过真机热稳态 Frame Timing 验收。

## 4. 规则等级与维护

| 标识 | 含义 |
|---|---|
| 🔴 | 适用条件满足时必须执行 |
| 🟡 | 推荐，结合渲染管线版本、硬件档位与视觉目标选择 |
| 🟢 | 可选，仅在带来明确画质或性能收益时采用 |

- 🔴 具体引擎与 URP 版本 API（如 URP 12 / 14 / 17 RenderGraph）以项目 `Packages/manifest.json` 实际版本为准，严禁混用不兼容版本的内部宏或管线钩子。

## 5. 完成检查

- [ ] 渲染管线与自定义 Shader 已核对单通道立体渲染（Single-Pass Instanced）兼容性。
- [ ] 关键材质满足 SRP Batcher 或项目既定合批路径，无隐性破批调用。
- [ ] 特效粒子数、透明屏幕占比、Overdraw 与序列帧贴图在目标预算内。
- [ ] Shader 变体关键字已收口裁剪，打包前无失控变体爆炸风险。
- [ ] 已明确区分编辑器预览与目标真机热稳态剖析证据。
