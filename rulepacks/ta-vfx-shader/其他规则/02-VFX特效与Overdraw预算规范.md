# 02 - VFX 特效与 Overdraw 预算规范

> - 🟢 本文件适用于实时 3D 与 XR 项目的粒子特效（Shuriken / VFX Graph）性能体检、半透明 Overdraw 控制、序列帧资源与对象池生命周期规范。
> - 🔴 不适用：将某一类特效的粒子数量硬性一刀切套用到所有档位设备，而不结合屏幕占比与 Overdraw 实测评估。

---

## 1. Overdraw 是移动 XR 特效的头号杀手

相比“粒子有多少个”，决定移动 XR 一体机 GPU 是否崩盘的关键往往是**像素填充率（Fillrate）与半透明层叠次数（Overdraw）**：10 个占满半个屏幕的半透明烟雾粒子，其 GPU 代价往往远超 200 个微小的火星粒子。

- 🔴 **严禁大面积半透明粒子持续贴脸或覆盖整屏**：避免烟雾、光晕、能量罩、体积光在用户近距离（尤其是穿过特效时）形成 6–10 层以上全屏半透明叠加；必要时在 Shader 或逻辑中增加**近距相机淡出（Camera Distance Fade）**。
- 🔴 **必须使用紧密裁切网格（Tight Mesh）替代大块透明空边四边形（Quad）**：粒子贴图边缘若有 40%–60% 为全透明像素，使用默认方形 Quad 会让 GPU 白白执行大量空像素片元着色；应通过 Sprite Tight Mesh 或 6/8 边形定制面片裁掉无效透明区域。
- 🔴 **慎用 Alpha Test（`clip` / `discard`）与昂贵软粒子**：在移动 TBDR GPU 上，`discard` 会打断 Early-Z 硬件剔除优化；非必要不要把普通透明粒子改写成 Alpha Clip，也不要为了极微小的边缘柔和在移动一体机上盲目开启全局深度图采样软粒子。

## 2. 粒子系统结构与峰值控制

| 体检项 | 常见超标隐患 | 规范要求 |
|---|---|---|
| **Max Particles 上限** | 保持默认 `1000` 不调，导致内存预分配浪费与突发超限 | 🔴 每个子发射器必须按实际视觉峰值收敛 `Max Particles` |
| **子发射器嵌套深度** | 单个特效 Prefab 内嵌 15–20 个冗余子粒子系统且各用不同材质 | 🔴 合并同类材质发射器，控制单特效子系统数量与材质球种类 |
| **Collision / Lights / Trails 模块** | 在大量粒子上开启物理碰撞、每粒子点光源或高频拖尾 | 🔴 移动 XR 严禁开启 Particle Lights；粒子物理碰撞仅限极少数关键表现并做性能实测 |
| **屏幕外与休眠剔除** | 特效离开视野或已播完仍持续 `Simulate` 占用 CPU | 🔴 配置合理的 `Culling Mode` 与播完自动停止/回收机制，不残留空跑循环粒子 |
| **Prewarm（预热）尖峰** | 大量高粒子数特效启用 Prewarm，生成瞬间主线程卡顿 | 🔴 对高频触发特效优先采用对象池复用，避免实例化瞬间触发高开销 Prewarm |

## 3. 特效贴图、序列帧与色彩规范

- 🔴 **序列帧动画必须合并为图集（Flipbook Atlas）并对齐 2 的幂次方**：禁止用几十张独立零散贴图逐帧切换，减少采样与内存碎片；合理控制帧数（如 4×4 / 6×6 / 8×8 结合平滑插帧 `Blend Frames`），不盲目追求 4K 巨型序列帧。
- 🔴 **单通道灰度遮罩打包复用**：噪波图（Noise）、溶解图（Dissolve）、渐变遮罩（Mask）应打包到单张贴图的 R/G/B 通道，搭配材质色（Vertex Color / Tint）着色，严禁为同形状不同颜色的特效重复存多张彩色贴图。
- 🔴 **检查混合模式（Blend Mode）与色彩空间**：Additive（叠加）与 Alpha Blend（透明混合）须在项目真实线性空间（Linear）与暗/亮背景（尤其是 MR 透视亮背景）下验证可见度，防止 Additive 特效在亮色 MR 现实墙面前完全“发白消失”。

## 4. 特效目录树、命名与跨项目资产复用规范

特效若不从立项起区分**共享底材**与**成品预制体**，极易因交叉引用与业务硬耦合沦为一次性资产，无法跨场景或跨项目复用。

### 4.1 推荐目录树与命名约定

若项目尚无既有 VFX 目录结构，默认采用“共享原子层 + 成品预制层 + 隔离实验层”三区目录（项目已有目录或前缀约定时严格沿用，若同时安装了 `unity` 默认 `Mat_` / `Shader_` 与 `3d-art` 默认 `M_`，须在 `.agent-rules/overrides.md` 中锁定项目唯一前缀与根目录映射，严禁混用）：

```text
Assets/Art/VFX/
├── _Common/                 # 跨特效 / 跨项目共享原子库（严禁反向引用具体业务）
│   ├── Shaders/             # 通用 VFX Shader（溶解 / 扭曲 / 菲涅尔 / 光晕，含立体渲染宏）
│   ├── Textures/
│   │   ├── Noise/           # 单通道或 RGB 通道打包灰度噪波图
│   │   ├── Masks/           # 通用渐变 / 光晕 / 软边遮罩图
│   │   ├── Flipbooks/       # 通用火焰 / 烟雾 / 火花序列帧图集
│   │   └── Ramps/           # 通用色彩映射图（LUT / Ramp）
│   ├── Meshes/              # 通用特效网格（圆柱 / 圆环 / 条带 / Tight Mesh 面片）
│   └── Materials/           # 通用基础材质球（优先复用并配合合批分组）
├── Presets/                 # 可直接复用的成品特效包（按业务域分组：Interact / Combat / UI / Env）
│   └── VFX_<域>_<名称>/      # 单特效自包含目录
│       ├── VFX_<域>_<名称>.prefab        # 根 Prefab（基准缩放 1,1,1、零业务脚本硬耦合）
│       ├── M_VFX_<域>_<名称>_*.mat       # 仅本特效专有材质实例（引用 _Common 资源）
│       └── VFX_<域>_<名称>_Preview.png   # 可选：预览图，用于资产库检索
└── _Sandbox/                # 个人实验与临时测试场景（严禁正式场景引用，不随资产库入库）
```

| 资产类型 | 建议命名模式 | 示例 |
|---|---|---|
| 成品特效 Prefab | `VFX_<领域>_<行为>_<变体>` | `VFX_Interact_LaserHit_01` |
| 特效材质球 | `M_VFX_<主名称>_<用途>` | `M_VFX_LaserHit_Glow` |
| 特效贴图 | `T_VFX_<名称>_<Noise\|Mask\|Flipbook\|Ramp>` | `T_VFX_Smoke_Flipbook_4x4` |
| 特效专用网格 | `SM_VFX_<名称>` | `SM_VFX_ShockwaveRing` |
| 特效 Shader / ShaderGraph | `S_VFX_<名称>` / `SG_VFX_<名称>` | `SG_VFX_UberAdditive` |

### 4.2 可复用特效资产 5 条硬标准

- 🔴 **单向依赖与零业务硬耦合**：`Presets/` 只允许单向引用 `_Common/` 与自身目录，严禁硬绑定具体关卡对象、业务 C# 脚本或 `Resources/` 硬编码路径；逻辑触发（播放、停止、变色、缩放、对象池回收）通过轻量通用控制组件或标准接口解耦。
- 🔴 **参数化复用（保合批）**：优先通过 1–2 个通用 VFX Uber Shader + `_Common` 通道打包灰度图 + Particle System `Vertex Color` / `Custom Vertex Streams` 控制颜色、溶解度、UV 偏移与亮度，严禁仅为换色复制整套材质与贴图。
- 🔴 **尺度、轴向与缩放模式标准化**：遵循 1 单位 = 1 米比例，根 Prefab Transform 归零且缩放 `(1, 1, 1)`，粒子系统显式配置 `Scaling Mode = Hierarchy`（避免跨场景缩放时粒子尺寸失真），方向性特效统一朝向 `+Z` 前向。
- 🔴 **独立打包交付验证**：可复用特效库（`_Common/` + 选定 `Presets/`）应支持以 `.unitypackage` 或 Unity UPM Package（含 `package.json` 及 URP 最低版本声明）独立导出并在空白/新目标工程导入验证，确保零缺图、零报错、无粉红材质。
- 🟡 **入库资产卡片**：每个沉淀入库的复用特效附预览图与关键性能标签（峰值粒子数、材质/DrawCall 数、Overdraw 评估、已验设备档位与 MR 亮背景可见性），便于团队检索与跨项目复用。

❌ 反例：每个特效在场景目录随手新建同名重复贴图和私有 Shader，Prefab 直接挂载某关卡专属业务逻辑脚本且根缩放为 `(0.35, 0.35, 0.35)`，复制到新工程后材质全粉且脚本报错。

✅ 正例：特效归档在 `Assets/Art/VFX/Presets/VFX_Interact_ScanWave/`，仅引用 `_Common/` 的通用 Uber Shader 与通道打包噪波图，根缩放 `(1,1,1)`、`Scaling Mode = Hierarchy`，打包为独立 UPM/unitypackage 拖入新项目即可直接播放。

## 5. 特效性能与复用体检必查清单

- [ ] 单特效及典型战斗/交互高峰场景的 Overdraw 视图已检查，无大面积高叠加红区。
- [ ] 已检查所有粒子贴图透明留白，大面积特效已启用紧密裁切网格或优化贴图占比。
- [ ] 所有子发射器 `Max Particles` 已收敛，无无用 Lights / Physics Collision / 失控 Prewarm。
- [ ] 特效播放结束后能正确回收或停止模拟，支持对象池复用且热路径无持续 GC 分配。
- [ ] 目录位置与命名符合规范，单向依赖 `_Common/` 且无业务脚本/场景硬耦合，根缩放 `(1,1,1)`、方向朝 `+Z`、`Scaling Mode` 配置正确。
- [ ] 已在双目立体渲染与目标背景（含 MR 亮暗场景，如适用）下核验无穿帮和消失问题。
