# 00 - JavaScript AI 编码规则文档总览

> - 🟢 本规则库适用于 JavaScript 项目的浏览器、Node.js、Electron（主进程 / preload / 渲染进程）、CLI、Worker 及项目已采用框架（React / Vue 等）的开发、测试、配置和维护；运行时、框架和工具均以仓库实际事实为准。
> - 🔴 不适用：TypeScript 独有类型规则（见同级规则包 `typescript`）、框架深度用法，或将示例中的框架、构建工具与第三方服务当作所有项目的默认前提。

---

## 1. 核心原则

1. 项目的 `package.json`、锁文件、运行时版本、构建配置、源码、测试和部署事实优先于本规则库示例。
2. 优先完成最小可验证改动；未经授权不升级运行时、包管理器、框架、模块系统或工具链。
3. 不确定时说明证据缺口或询问用户，不以通用经验或 AI 幻觉补全项目事实，不过度设计。
4. 代码、测试、配置与运行方式共同构成事实来源，不能只根据目录或单个依赖猜测技术栈。

## 2. 规则等级与优先级

| 等级 | 标识 | 含义 |
|------|------|------|
| 必须 | 🔴 | 当前适用场景必须遵守；无法执行时说明原因、范围和风险 |
| 推荐 | 🟡 | 满足适用条件时优先评估；项目事实、风险和成本不支持时不采用 |
| 可选 | 🟢 | 按项目实际灵活选择 |
| 安全 | 🟠 | 涉及对应威胁时必须处理，具体措施以项目威胁模型为准（见 [11 - 安全规则](./其他规则/11-安全规则.md)） |

优先级依次为：用户当前任务与安全限制、目标工程代码/依赖/配置/测试和已有项目约定、`.agent-rules/overrides.md` 中的项目覆盖规则、[15 - JavaScript AI 通用入口规则](./15-AI通用入口规则.md) 与当前任务相关专题规则。

## 5. 跨语言继承

JS 是运行时基线层（`typescript` 规则包的上游）。TS 项目先加载 JS 通用入口，再按任务选择 JS 与 TS 专题，不要求一次读取全部文件。

## 6. AI 工具接入与维护

规则包版本、依赖与规则清单以同目录 `pack.json` 为准。安装由智枢 CLI 和目标工具适配器负责；适配器只做入口导航，完整规则维护在本规则包中。

- 🔴 修改专题规则后，同步检查本总览的任务查表、交叉链接、入口路由和 `pack.json` 清单。
- 🔴 不把特定运行时、框架、构建工具、命令或第三方服务写成默认事实；需说明适用条件和验证方式。
- 🟡 新增规则前先确认现有专题无法承载，避免规则碎片化。
