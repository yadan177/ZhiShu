# 智枢桌面版 2.2.0

本版本为全产品深度审计后的系统性质量修复与功能闭环升级版（搭配规则包 / CLI / 岗位插件 `v2.1.0` 双轨运行），一次性扫清全部 5 大功能模块、应用内更新器、核心引擎、跨宿主适配与打包链路中的 P0/P1/P2 缺陷。

## 核心更新与修复

### 1. 打通全部冲突与异常态恢复闭环（终结灰按钮死胡同）
- **我的项目 & 项目规则**：新增「覆盖修复」与「强制卸载 / 清理孤立锁文件」可审查差异流程（严格保留 `.agent-rules/overrides.md` 与项目非受管文件）；升级项目操作锁为结构化 PID 锁，支持真实进程崩溃后的死锁接管恢复；补齐「我的项目」与「项目规则」手动「刷新」、更新态「重新检查」、无 `common` 本地源与自定义私有包分组支持。
- **插件与技能 / AI 工具 / MCP**：冲突行不再停在灰置「卸载」按钮，新增可审查差异的 **「覆盖修复」**、**「强制卸载」** 与不改动目标目录的 **「清除记录」**；修复 `zhishu-desktop` 升级至 `智枢` 时旧版 Codex 插件与旧版 MCP 回执漏扫问题；过期旧回执（如 `v0.1.5`）遇磁盘合法官方插件（如 `v2.1.0`）自动切换干净接管，并统一规范化 `sourceDigest` 与 JSON 键序哈希；支持多勾选接管、自定义 MCP 编辑与重复 ID 拦截、HTTP 带连字符 Header（如 `X-API-Key`）与 MCP 更新检测。
- **规则进化**：对 `pending / conflict / stale` 全部待审态提供「重新检测」并支持将抽屉中编辑后的补丁落盘重检解除冲突，预览冲突弹窗新增「重新检测并重预览」；将 Git 同步镜像缓存标记为只读（仅导出补丁），防止后续来源同步 `reset --hard` 覆盖已审批写入；官方文档巡检切页自动保持进度与取消状态、接入系统代理且补齐 3xx 重定向 SSRF 防护；新增「重新打开」「归档」「恢复默认巡检源」及同机 CLI 提案文件监听自动刷新。
- **来源管理**：新增来源「编辑」与移除二次确认弹窗，修复删除来源后残留临时工作区引用与 `git clone` 失败残留半成品 `.git` 的问题。

### 2. 全局交互体验、并发安全与更新器加固
- **弹窗内联报错与并发写锁**：全部弹窗与右侧抽屉改用内联错误展示，彻底避免报错被半透明遮罩挡住；主导航在子页面写操作进行时自动锁定防竞态；`PreviewDialog` 补齐 `Esc` 关闭与焦点恢复；修复 `Dropdown` 贴近滚动边缘打开即闪退关闭的问题。
- **应用内更新器与传输链路**：修复下载中断/超限时的流关闭顺序与残文件清理、补齐空闲超时与背压保护；修复 macOS 自动替换脚本 4 处边界问题；Windows 安装改用 `shell.openPath` 原生支持 `Program Files` UAC 提权；清理 `142 MB` 未引用及重复打入 `app.asar` 的前端依赖，显著缩减安装包体积。
- **跨宿主与 CLI 加固**：扩展 GUI 场景下的 Codex CLI 路径探测与单飞缓存；TRAE 探测兼容 `/Applications/TRAE CN.app`；处理 `codex` 与 `generic` 共用 `~/.agents/skills` 的碰撞提示；CLI 参数解析器支持 flag 与目录任意顺序并拒绝未知参数，补齐 `zhishu evolve recheck` / `reopen`。

## 安装与说明

- macOS 提供 Apple Silicon DMG（`ZhiShu-Desktop-2.2.0-macOS-arm64.dmg`），Windows 提供 x64 EXE（`ZhiShu-Desktop-2.2.0-Windows-x64.exe`），随 Release 同步附带 `SHA256SUMS.txt`。
- 已安装 `2.1.3` 及以上版本的用户可直接在软件左下角点击「检查软件版本 → 下载更新」完成应用内校验与一键更新；首次从浏览器下载 macOS 安装包如遇“未验证开发者”提示，请在「系统设置 → 隐私与安全性」点击「仍要打开」放行一次。
