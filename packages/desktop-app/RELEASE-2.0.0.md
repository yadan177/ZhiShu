# 智枢桌面版 2.0.0

本版本正式更名为 **智枢（ZhiShu）**，与规则包 / CLI `v2.0.0` 双轨同步发布，升级为面向企业与个人全岗位 AI 工程资产管理的 2.0 架构。

## 核心更新

- **全新 2.0 左侧 4 模块架构与系统字体统一**：重构「我的项目 / 项目规则」「插件与技能」「AI 工具」「来源管理」四大工作台；应用名、图标与菜单全面升级为「智枢」；全界面文字统一采用操作系统默认无衬线字体（macOS 苹方 / Windows 微软雅黑），仅在代码与文件 Diff 预览框保留系统等宽字体。
- **20 规则包多岗位组合与空间 UI 规范体系**：支持多岗位/多技术栈按需组合安装（含 `xr-common`、`product-pm`、`ui-design` 及新增 XR 空间布局摆放规范、`3d-art`、`ta-vfx-shader` 与 Unity XR 空间 UI 实现规范）；项目规则页首次安装主操作收口为「安装规则 → 变更预览 → 确认安装」，并支持可视化中断事务恢复。
- **6 大官方岗位插件（42 个 Skills）与跨工具同步**：内置产品经理、UI 设计师、三维设计师、技术美术（TA）、Unity 开发工程师与全栈开发工程师 6 大岗位插件（新增覆盖产品、UI、Unity 与跨端研发的 4 份空间 UI 协同 Skills），支持一键预览同步到 Antigravity、OpenAI Codex、TRAE 与通用目录（`~/.agents/skills`）。
- **独立 MCP 脱敏配置与 AI 工具全生命周期管理**：内置飞书 MCP 预设并支持添加自定义 `stdio` / `http` MCP，密钥仅写入本机配置且预览自动脱敏；「AI 工具」页统一盘点本机已装插件、技能与 MCP。
- **三级资产来源治理**：新增「来源管理」支持企业私有 Git / 本地目录源（含企业必选规范锁定与 `0o600` 凭据隔离）、个人源与官方只读源。

## 安装与说明

- macOS 提供 Apple Silicon DMG（`ZhiShu-Desktop-2.0.0-macOS-arm64.dmg`），Windows 提供 x64 EXE（`ZhiShu-Desktop-2.0.0-Windows-x64.exe`）；下载后手动安装。
- 若本机此前安装过旧版「AI 开发工具箱」，安装新版「智枢」后可按需自行移除旧包。
- 当前安装包尚未配置代码签名与 macOS 公证，首次打开时系统可能提示安全确认；Windows 端实机交互、TraeWork 本地技能识别与 Qoder / Cursor / WorkBuddy 规则客户端加载仍待持续实测验收。
