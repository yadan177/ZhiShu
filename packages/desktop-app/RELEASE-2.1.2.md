# 智枢桌面版 2.1.2

本版本为桌面端应用内安全更新能力升级版（搭配规则包 / CLI / 岗位插件 `v2.1.0` 双轨运行），新增「应用内流式下载 + 双向 SHA-256 强校验 + 跨平台一键安装」闭环；升级至 `2.1.2` 后，后续 `2.1.3+` 桌面端更新无需再手动打开浏览器查找下载链接。

## 核心更新

- **应用内流式下载与双向 SHA-256 强校验**：
  - CI 发版同步生成并上传 `SHA256SUMS.txt`，客户端同时核对 `SHA256SUMS.txt` 与 GitHub Release 不可变资产摘要（`asset.digest`），并逐跳校验受信任的 HTTPS / GitHub CDN 重定向域与 `512 MiB` 体积上限。
  - 左下角版本卡片新增实时下载进度条、`取消` 按钮、已校验缓存包复用、旧版缓存自动清理，以及失败后的「重试更新」与「浏览器下载」兜底入口。
- **跨平台安全安装与重启保护**：
  - 下载并校验通过后明确停留在 `已就绪` 态，由用户主动点击「安装并重启 / 安装更新」，同时沿用「文件操作进行中禁止安装重启」护栏，启动前再次执行 TOCTOU SHA-256 复核。
  - **macOS**：位于可写 `/Applications` 或 `~/Applications` 时，退出后以 `hdiutil attach` + `ditto` + 原子目录切换（异常自动回滚并回退打开 DMG）自动替换 `.app` 并重启；位于只读/转译目录时自动打开已校验的 DMG 安装包。
  - **Windows**：若具备代码签名与 `latest.yml` 沿用 `electron-updater`，否则校验通过后直接拉起新版 `.exe` 安装向导并退出旧版。

## 安装与说明

- macOS 提供 Apple Silicon DMG（`ZhiShu-Desktop-2.1.2-macOS-arm64.dmg`），Windows 提供 x64 EXE（`ZhiShu-Desktop-2.1.2-Windows-x64.exe`），随 Release 同步附带 `SHA256SUMS.txt`。
- 本次从 `2.1.1` 及更早版本升级到 `2.1.2` 仍需手动安装一次；自 `2.1.2` 起后续桌面版本均可直接在左下角点击「下载更新 → 安装并重启」。
- 当前安装包尚未配置代码签名与 macOS 公证，首次打开时系统可能提示安全确认；Windows 实机安装向导拉起与 macOS 跨版本热替换需在发版后通过真机包复测验证。
