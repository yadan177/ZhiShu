# 智枢桌面版 2.1.1

本版本为桌面端体验与升级治理补丁版（搭配规则包 / CLI / 岗位插件 `v2.1.0` 双轨运行），按完整产研设计流程重设 **「04 · AI 工具」** 页面布局，并新增旧版回执与未纳管官方插件的「零静默写入」显式接管闭环。

## 核心更新

- **「AI 工具」页面紧凑横排与按状态条件显隐**：
  - 顶部 4 张本机工具探测卡片补齐支持能力摘要与分类计数（插件 / 技能 / MCP），点击筛选后在列表头展示状态汇总徽章（`正常 / 可更新 / 需处理`）与「查看全部」复位入口。
  - 已安装清单由旧版三行竖排重构为单行左信息 / 右操作紧凑卡片，安装路径自动精简为 `~/...`（悬停查看完整绝对路径），在 `920×680` 最小窗口下保持零横向溢出。
  - 彻底消除已是最新单版本条目的无效控件：最新单版本仅显示状态徽章与「卸载」；存在更高版本时显示「可更新至 vX.Y.Z」与主操作「更新」；仅本地存在 `>= 2` 候选版本时展示紧凑自定义版本下拉框；MCP 仅展示状态、「环境变量」与「卸载」。
- **旧版回执与未纳管官方插件显式接管（零静默写入）**：
  - 新增 `assets:inspect-legacy` 只读扫描：自动识别旧版 `zhishu-desktop` 遗留回执，以及 `~/.gemini/config/plugins/` 下满足 `author.name === "智枢官方"` 且命中官方预设名录的未纳管 `zhishu-*` 插件（严禁误扫第三方插件、幽灵回执或符号链接）。
  - 新增提示条「接管旧版」与「接管旧版记录」预览弹窗，仅在用户点击「确认接管」后通过互斥锁以 `0o600` 原子补写智枢本地回执，绝不修改目标工具目录中的已有文件；接管后可直接在已安装清单中无冲突升级至最新版本。

## 安装与说明

- macOS 提供 Apple Silicon DMG（`ZhiShu-Desktop-2.1.1-macOS-arm64.dmg`），Windows 提供 x64 EXE（`ZhiShu-Desktop-2.1.1-Windows-x64.exe`）；下载后手动安装。
- 当前安装包尚未配置代码签名与 macOS 公证，首次打开时系统可能提示安全确认；Windows 实机交互与真机打包路径仍待持续实测验收。
